## 📝 Programs Included

### 📌 Main Practice (`index.html`)

This program demonstrates various CSS text properties.

**Concepts Covered**

- Text Alignment
- Text Decoration
- Font Family
- Font Size
- Font Weight
- Text Transformation
- Line Height
- Removing Underline from Links

---

### 📌 Problem 1

**Task**

Create a heading centered on the page with all of its text capitalized by default.

**Concepts Used**

- `text-align`
- `text-decoration`
- `font-size`
- `font-family`
- `font-weight`
- `text-transform`

---

### 📌 Problem 2

**Task**

Set the font family of the entire document to **Times New Roman**.

**Concepts Used**

- Universal Selector (`*`)
- `font-family`

---

### 📌 Problem 3

**Task**

Create one `div` inside another `div`.

- Outer div text size: **25px**
- Inner div text size: **10px**

**Concepts Used**

- Nested Elements
- `font-size`
- CSS ID Selector

## 📖 CSS Properties Practiced

| Property | Purpose |
|----------|----------|
| `text-align` | Align text horizontally |
| `text-decoration` | Add or remove text decoration |
| `text-transform` | Convert text case |
| `font-family` | Change font style |
| `font-size` | Change text size |
| `font-weight` | Change text thickness |
| `line-height` | Control spacing between lines |
