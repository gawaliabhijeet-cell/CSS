### 4️⃣ Align Items vs Align Self

**Task**

Understand the priority between:

- `align-items`
- `align-self`

### Result

✅ `align-self` has higher priority because it overrides the `align-items` property for an individual flex item.

### Responsive Color Changing Div

This example changes the background color of a `<div>` based on the viewport width.

| Screen Width | Background Color |
|--------------|------------------|
| Less than 300px | 🟢 Green |
| 300px – 399px | 🩷 Pink |
| 400px – 599px | 🔴 Red |
| Above 600px | 🔵 Blue |

# 📖 CSS Properties Practiced

| Property | Purpose |
|----------|----------|
| `position` | Defines element positioning |
| `top`, `left`, `right` | Moves positioned elements |
| `display: flex` | Creates a flexible layout |
| `justify-content` | Aligns items horizontally |
| `align-items` | Aligns all items vertically |
| `align-self` | Aligns an individual flex item |
| `flex-grow` | Allows an item to grow |
| `flex-shrink` | Allows an item to shrink |
| `background-image` | Adds an image as the background |
| `background-size` | Controls background image scaling |
| `@media` | Applies responsive styles based on screen size |
