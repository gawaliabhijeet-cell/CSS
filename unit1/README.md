# 🎨 CSS Level 1 Practice

This repository contains my CSS Level 1 practice programs while learning the fundamentals of HTML and CSS.

## 📚 Topics Covered

- HTML Basics
- External CSS
- Inline CSS
- Internal CSS
- CSS Selectors
  - Element Selector
  - Class Selector
  - ID Selector
- Text Color
- Background Color
- CSS Priority (Inline > Internal > External)

---

## 📂 Programs Included

### 1. Basic CSS Selectors
- Using ID selector
- Using Class selector
- Styling headings, paragraphs, and buttons

### 2. Multiple Headings
- Creating `h1`, `h2`, and `h3`
- Applying the same class to multiple elements

### 3. Div with Background Color
- Creating a `div`
- Setting background color
- Adding text inside the div

### 4. CSS Priority Example
Demonstrates the priority of CSS:

1. Inline CSS (Highest Priority)
2. Internal CSS (`<style>`)
3. External CSS (`style.css`)
